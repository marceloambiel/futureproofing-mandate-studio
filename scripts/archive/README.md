# Historical diagnostics

These scripts target earlier prototype labels and screen structures. They are retained for provenance and are not part of the supported verification workflow.

- `focus-diagnostic.mjs`: an earlier comparison-dialog keyboard investigation.
- `capture.mjs`: original v1 workflow captures using retired controls.
- `capture-states.mjs`: captures of earlier disclosure and recovery states.

Use the current browser tests in `tests/e2e/current/` and `scripts/capture-process-journey.mjs` for the finished prototype. Run scripts from the repository root; generated evidence belongs under ignored `docs/run/` paths.
